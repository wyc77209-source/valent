Oasis SDK 2.0: The Agentic Layer

Inspired by OpenAI's Clawdbot/NemoClaw self-improving architecture. Deploy Agents that don't just call APIs — they evolve their own logic to better achieve your goals over time.

oasis_agent_deploy.py
# Oasis SDK 2.0 — Deploy a self-evolving Agent
from oasis import AgentBuilder, EvolutionPolicy

# Define the Agent's goal and constraints
agent = AgentBuilder()
  .goal("Monitor oncology papers daily")
  .tools(["arxiv_search", "slack_notify"])
  .routing({
    "default": "qwen-max",      # cheap
    "high_priority": "claude-opus" # powerful
  })
  .evolution(EvolutionPolicy.AGGRESSIVE)
  .deploy()

# Agent is now live on the Oasis fabric
# It will self-optimize every 24h cycle
print(agent.endpoint)
# → https://oasis.run/agents/clin-monitor-v1

// Privacy-Preserving Inference Flow
1
Hospital Data Stays On-Premise
Patient records, imaging data, and clinical notes remain within the hospital's NVIDIA Clara-secured environment. Zero raw data egress.
2
Encrypted Inference Request
The Oasis SDK sends an encrypted, attested inference request to the hospital's Clara node. The model runs locally inside a Trusted Execution Environment (TEE).
3
Only Tokens Flow Out
The inference result (e.g., "High-risk: 87% probability") is the only data that leaves the secure enclave. No images, no records, no PII.
4
Proof-of-Compute Reward Issued
The hospital's node receives Oasis Protocol Rewards (OPR) for every verified inference. Medical-grade compute earns a 5x multiplier over standard compute.
